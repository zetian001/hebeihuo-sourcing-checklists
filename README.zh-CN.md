# 河北商品采购询价核对表

比较两家供应商的报价，先要确认两者报的是同一款商品、同一规格和同一交付范围。这份清单供采购商复制使用，不代表对任何供应商的认证。

1. 写明商品款式、材质、尺寸、公差、重量或 GSM，以及用途和销售目的地。
2. 请供应商写明报价币种、计价单位、适用数量、有效日期和具体配置。
3. 分开询问 MOQ、样品费、打样时间、Logo 或模具费用。
4. 写明包装方式、装箱数量和破损防护要求。玻璃器皿尤其需要确认包装和运输损耗；童车、自行车应确认装配状态。
5. 将货价、国内运费、国际运费和目的地费用分开比较，并明确交货条款。
6. 核对企业法定名称、商务联系方式和这一款商品的实际生产地点。注册地址不等于每件商品的生产地。
7. 确认交期、验货标准，以及样品与大货不一致时的处理方式。

可复制使用[空白询价模板](RFQ-TEMPLATE.md)。[河北货商品库](https://hebeihuo.com/zh/)按商品、产业带和企业档案组织公开资料；例如[白沟箱包](https://hebeihuo.com/zh/industries/baigou-bags/)与[高阳家纺](https://hebeihuo.com/zh/industries/gaoyang-textiles/)可作为寻找具体款式的起点。公开参考价不是实时成交报价，最终价格与交易条件需向供应商确认。
